## 🔧 技术要点

- Three.js（r170 自包含构建）ES Modules，无打包、无外部素材
- 全部纹理为运行时 Canvas 程序生成的 16×16 像素图集（含物品图标伪 3D 渲染）
- 生物由 Blender 5.2 无头建模导出 GLB（部件独立枢轴，JS 端做行走摆臂/头部追踪动画）
- 光照：天光列灌注 + 双通道 BFS 增量更新，烘进顶点色，着色器 `min(sky×uDay + block, 1)` 合成
- 区块 16×96×16，AO 四级，水面顶点波动着色器
- 存档：种子 + 方块差异稀疏表 + 玩家/容器状态 → localStorage
- 音效：WebAudio 实时合成（挖掘/脚步/爆炸/僵尸低吼/弓箭/五声音阶环境乐）
